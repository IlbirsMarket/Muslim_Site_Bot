## Особенности схемы Swagger

В DishPublic поле extras описано как строка, но фактический ответ содержит список объектов добавок. Клиент обрабатывает фактический формат. Метод переключения наличия принимает пустой объект, хотя Swagger описывает полное блюдо. Действие claim из списка доступных действий отправляется отдельным запросом /claim/, а не через /status/.
