# Муслим — сайт и админ-панель

## Установка и запуск рядом с бэкендом

Требуется Node.js 22 или новее. Из корня репозитория:

```powershell
cd frontend
npm ci
$env:MUSLIM_API_ORIGIN = 'http://127.0.0.1:8000'
npm start
```

Для macOS/Linux: `MUSLIM_API_ORIGIN=http://127.0.0.1:8000 npm start`.
Бэкенд запускается отдельно из корня репозитория по своей инструкции. Укажите адрес компьютера с Django, если он работает на другой машине. Переменная задаёт адрес без `/api/` в конце; сервер добавляет путь сам. Файлы `.env` этот сервер автоматически не читает.

Гостевое меню: http://localhost:4174/ . Панель сотрудников: http://localhost:4174/admin . Django admin остаётся на http://127.0.0.1:8000/admin/ . Это разные панели.

Ветка содержит готовые статические файлы в `dist/`; отдельная сборка не требуется. `server.cjs` предназначен для локальной разработки. Для продакшена нужно настроить HTTPS, адрес API и раздачу гостевых QR-ссылок. Публикация только `dist/` оставляет демонстрационный режим из `runtime-config.js`.

Раздел «Проверка API» доступен только программисту. Реальные права на данные проверяет Django API.

## Состав проекта

Локальный запуск с API: `npm start`, затем http://localhost:4174/admin . Гостевое меню: http://localhost:4174/ . Запуск без API: `npm run start:demo`.

Настроенный Swagger: http://172.20.10.4:8000/api/docs/ . Секреты и тестовые пароли не хранятся в исходниках. Вход выполняется через форму, токены живут в сессии вкладки. Адрес сервера можно изменить через MUSLIM_API_ORIGIN.

Админ-панель содержит заказы, редактор блюд с фото и размерами, столы и QR, роли, отчёты, настройки и проверку API. Роли и доступные действия поступают с сервера. В демонстрационном режиме данные отдельно хранятся в браузере.

`npm run check` — синтаксис всех скриптов. `npm test` — тесты API-клиента, прокси и локального хранилища.

Подробности подключения: [docs/API-INTEGRATION.md](docs/API-INTEGRATION.md). Результаты проверки: [docs/API-VALIDATION.md](docs/API-VALIDATION.md).

Публикуемые статические файлы находятся в dist/. Локальный сервер находится в server.cjs. API-клиент — dist/api.js, конфигурация — runtime-config.js. В опубликованной версии кнопка «Открыть с API» ведёт в локальную версию: текущий API доступен только в локальной сети.

QR-коды строит локальная библиотека qrcode-generator (MIT), лицензия включена в dist/assets/qrcode.js. Шрифты Manrope локальные, лицензия в dist/assets/FONT-LICENSE.txt.
