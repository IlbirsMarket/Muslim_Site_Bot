# Муслим — меню, панель сотрудников и API

- Бэкенд Django: `apps/`, `config/`, `core/`, `manage.py`, `requirements.txt`.
- Фронтенд: [`frontend/`](frontend/README.md) — гостевое QR-меню, заказы и панель сотрудников.

Фронтенд запускается отдельно на порту 4174 и пересылает запросы в Django API. Подробности установки и подключения находятся в `frontend/README.md` и `frontend/docs/API-INTEGRATION.md`.

Тесты фронтенда: `cd frontend`, затем `npm run check` и `npm test`. Они не меняют данные рабочего API. Скрипты `api-probe.cjs` и `api-flow.cjs` — отдельные проверки живого API; последний создаёт и удаляет собственные тестовые записи, поэтому запускается только на согласованном тестовом сервере.
